# Current external-agent demonstration — 10 November 2026

The current Codex terminal agent created one synthetic solo paper through the stock Agent-Native `runScript` CLI entry point, saved version 1, ran three typed checks and read the document/checks back. The real browser opened that same paper and saved the three checks through the UI. No caller identity, user email or reviewer thread was supplied or overridden. The normal framework development identity was used in an isolated local application copy.

The demo video is edited from actual captured application views, with English synthetic narration. Captures are cropped/resized for readability. No generated chat answer, cursor action or missing application result was manufactured. Codex operated the browser for the creator; this is not evidence of an independent human assessment.

## Prospective controls

| Case | Explicit inputs | Claim | Expected and observed |
|---|---|---|---|
| Isotropic area | 900 square pixels; 0.2 mm/pixel | 36 mm² | `matches`, exact 36 |
| Weighted mean, deliberate error | means 4 and 7; counts 7 and 13 | 6.05 | `differs`, exact 119/20 = 5.95 |
| Separate incomplete group | means 4 and 7; first count 7; second count null | 5.95 | `incomplete`, missing n_b |

A Python `Fraction` oracle was defined before the calls; all three results matched it. This is a small deterministic software demonstration, not a statistical model comparison, scientific dataset or efficacy study. The missing count must not be borrowed from the complete example.

Each saved record retains the caller-supplied inputs, formula, units, claim, exact fraction, tolerance and paper/version binding. That binding does not authenticate the source measurements or extract them from the document. Solo status `final` means the draft is saved; it does not mean the tribunal accepted it. No paper was published to P2PCLAW.

The framework Settings audit page displayed no events during this run. This demo demonstrates the application’s persisted numeric records and CLI receipts; complete cross-surface framework audit logging is not established here. Earlier reviewer-isolation tests and limited model workflows are separate evidence, not a current independent review of this fixture.

## Reproduce on your own local app

Install the pinned dependencies and start the app normally using the repository instructions. With Node.js 22.22+ and Python 3 on PATH, run `python examples/measurement-demo-20261110/run_demo.py` from this repository. It invokes the stock `actions/run.ts` using Node/tsx. The small `cli_json_output.mjs` preloader only formats stdout as JSON; it changes neither action execution nor authentication. Outputs stay in `.agent-native/measurement-demo-20261110` and persisted writes are checkpointed so a resumed script reuses the saved paper/version. Start a fresh output directory deliberately when you want a separate experiment.

The first Windows wrapper call failed before creation because its shell stripped JSON quotes. A subsequent creation succeeded, but inspection-formatted stdout was not JSON; the existing id was recovered before continuing, so no second paper was created. Both failures were retained privately. The direct stock runner and stdout preloader resolve these transport/format issues without editing application or framework code.
